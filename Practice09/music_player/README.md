# Music Player

## Description
A simple music player created using Python and Pygame.

## Features
- Play music
- Stop music
- Next track
- Previous track
- Display current song name
- Display playlist
- Playback progress bar
- Keyboard controls

## Controls
- P — Play
- S — Stop
- N — Next track
- B — Previous track
- Q — Quit

## Requirements
- Python 3
- Pygame
- Mutagen

## Run
```bash
python3 main.py
```
