# Practice 09

## Overview
This practice contains three Python projects developed using Pygame.

## Projects

### 1. Mickey's Clock
An animated clock created using Pygame. It uses image files to display the clock hands.

**Run:**
```bash
python3 mickeys_clock/main.py
```

### 2. Moving Ball
A simple animation where a ball moves across the screen.

**Run:**
```bash
python3 moving_ball/main.py
```

### 3. Music Player
A music player application that allows users to play, stop, and switch between songs.

**Features:**
- Play music
- Stop music
- Next track
- Previous track
- Display current track name
- Display playlist
- Show playback progress
- Keyboard controls

**Run:**
```bash
python3 music_player/main.py
```

## Requirements

Install dependencies:

```bash
python3 -m pip install -r requirements.txt
```
