# System Requirements — Food Delivery System

## 1. Introduction

Food Delivery System is a web application designed to simplify the process of ordering and delivering food online.

The system connects customers, restaurants, couriers, and administrators.

## 2. Functional Requirements

Functional requirements describe what the system must do.

### 2.1 Customer Requirements

- The customer must be able to register an account.
- The customer must be able to log in and log out.
- The customer must be able to browse available restaurants.
- The customer must be able to view food menus.
- The customer must be able to add food items to the shopping cart.
- The customer must be able to place an order.
- The customer must be able to view order status.

### 2.2 Restaurant Requirements

- The restaurant must be able to view incoming orders.
- The restaurant must be able to accept or reject orders.
- The restaurant must be able to update order status.
- The restaurant must be able to manage its menu.

### 2.3 Courier Requirements

- The courier must be able to view assigned deliveries.
- The courier must be able to accept delivery tasks.
- The courier must be able to update delivery status.

### 2.4 Administrator Requirements

- The administrator must be able to manage users.
- The administrator must be able to manage restaurants.
- The administrator must be able to monitor orders.

## 3. Non-Functional Requirements

Non-functional requirements describe the quality of the system.

### 3.1 Usability

The application should have a simple and user-friendly interface.

### 3.2 Performance

The application should respond to user requests within a reasonable time.

### 3.3 Security

- User passwords must be stored securely.
- Only authorized users should access protected functions.
- User information must be protected.

### 3.4 Reliability

The system should process orders accurately and maintain consistent information.

### 3.5 Maintainability

The application should have a clear structure that allows developers to update and improve it.

## 4. System Users

The system has four main user roles:

1. Customer
2. Restaurant
3. Courier
4. Administrator

## 5. Minimum Viable Product (MVP)

The first version of the application should include:

- User registration and login.
- Main page.
- Restaurant and food menu display.
- Shopping cart.
- Order placement.
- Basic order management.

Additional features can be implemented in future versions.

## 6. Project Constraints

- Development time is limited to the academic semester.
- Technologies will be selected by the project team.
- Features will be implemented according to available time and resources.

## 7. Future Improvements

Possible future improvements include:

- Online payment integration.
- Real-time delivery tracking.
- Customer reviews and ratings.
- Order notifications.
