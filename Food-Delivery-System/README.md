# Food Delivery System

## 1. Project Overview

Food Delivery System is a web application that allows customers to browse restaurants, view food menus, place orders, and receive food deliveries.

The system connects customers, restaurants, and delivery couriers through one platform.

## 2. Project Purpose

The main purpose of this project is to develop a convenient and user-friendly food delivery application.

## 3. User Roles

- **Customer:** Registers, browses restaurants, selects food, and places orders.
- **Restaurant:** Manages its menu and receives customer orders.
- **Courier:** Receives delivery requests and delivers orders.
- **Administrator:** Manages users and monitors the system.

## 4. Main Features

- User Registration and Login
- Restaurant Browsing
- Food Menu
- Shopping Cart
- Order Placement
- Order Management
- Delivery Status Tracking

## 5. System Components

- **Frontend:** User interface and application pages.
- **Backend:** Application logic and API endpoints.
- **Database:** Stores users, restaurants, menu items, and orders.
- **System Integration:** Connects the main components.
